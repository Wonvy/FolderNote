# Windows 11 首层菜单测试版

当前项目版本：**1.8.8**。此包让文件夹备注命令进入 Windows 11 新版右键菜单的应用区域，无需进入“显示更多选项”。Windows 可能将多个操作归入 FolderNote 子菜单；具体排序由系统决定，无法保证固定在“属性”紧下方。

## 安装

1. 下载独立安装包 **FolderNote-Setup-Win11-x64.exe**，无需解压或另外下载 MSIX。
2. 运行安装包，允许安装器请求的管理员授权。使用兼容 ZIP 时，仍需完整解压后运行 **Install-Win11.exe**，不要只安装 MSIX。
3. 从开始菜单搜索 **FolderNote 设置**。首次安装默认开启双击空白处返回上一级；备注和中键快速定位默认关闭。需要备注菜单时，开启“文件夹备注”并保存。
4. 关闭并重新打开需要使用的文件夹窗口。安装器使用独立版本目录覆盖升级，不强制结束资源管理器，也不要求注销。

安装器将应用包安装与导航自动加载注册合并处理。首层菜单版要求当前账户自身获得管理员授权；使用另一管理员的凭据时会停止，避免安装到错误账户。组织策略可能禁止未签名包或资源管理器扩展，程序不会绕过这些策略。

## 功能和升级

- 设置窗口左侧切换功能与置顶 / 历史管理，左下角显示当前运行版本。
- 备注、双击导航和中键快速定位可以独立启停。关闭备注功能只隐藏菜单，已有备注保留。
- 开启“中键快速定位”后，桌面和资源管理器均可使用菜单，并运行小型后台组件；从桌面选择文件夹会打开资源管理器窗口。勾选“同时支持文件与文件夹选择对话框”还可在标准打开 / 保存、选择文件夹及旧式“浏览文件夹”窗口使用。关闭中键快速定位后组件退出。
- 旧式窗口支持经典与可调整大小样式，菜单只提交目录定位，不点击“确定”；已有置顶和历史可用，但不推测树中当前目录，因此不显示“置顶当前文件夹”图标。管理员软件及自绘窗口不在支持范围；目标应用仍可按根目录或过滤规则拒绝某些路径。
- Windows 11 使用系统原生标签。FolderNote 的多标签栏、标签滚轮切换和悬停关闭按钮仅用于 Windows 10。
- 覆盖升级保留原有开关、主题、置顶和历史。非常早期版本的 MSIX 私有设置不会自动迁移，可重新打开设置并保存。
- 已运行的资源管理器可能缓存旧 DLL；关闭重开后仍未切换时，需要在结束文件复制 / 移动后重启资源管理器。

## 卸载和排查

在 Windows **设置 → 应用** 中卸载 **FolderNote 系统工具**，或运行安装目录内的 **Uninstall.exe**，完整移除当前用户的菜单包及导航组件，保留文件夹备注、用户设置和访问记录。仅删除同名 MSIX 包不会清理独立导航注册；`Install.exe --uninstall` 也不会移除 MSIX 包。

设置已保存但功能无反应时，先重新打开文件夹窗口，再检查设置左下角版本；可点击“复制诊断信息”查看扩展加载和选项状态。提交问题时请说明 Windows 版本、程序版本以及“新窗口 / 新标签页 / 旧窗口”中的复现情况。

## 验证与发布范围

1.8.6 在 Windows 10 22H2 上通过 18 组自动测试，Win11 包通过清单与 MakeAppx 打包校验。1.8.7 已完成无警告 Release 构建并通过 19 组 CTest（14.71 秒）；真实隐藏旧式对话框在 64 位及 32 位目标上各通过 39 项断言，覆盖两种样式、Unicode 路径和定位不自动确认等回归。1.8.7 已通过 MSIX 清单与 MakeAppx 打包校验。以上不能视作 Windows 11 24H2/25H2 安装、菜单显示及全部交互的实机验收。
