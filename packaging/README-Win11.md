# Windows 11 首层菜单测试版

**适用版本：1.9.12 · Windows 11 x64 · 未签名测试版**

[返回项目首页](../README.md) · [下载独立安装包](https://github.com/Wonvy/FolderNote/releases/latest/download/FolderNote-Setup-Win11-x64.exe) · [完整功能说明](../docs/USER_GUIDE.md)

此包让文件夹备注命令进入 Windows 11 新版右键菜单的应用区域，无需进入“显示更多选项”。Windows 可能将多个操作归入 FolderNote 子菜单；具体排序由系统决定，无法保证固定在“属性”紧下方。

## 安装

1. 下载独立安装包 **FolderNote-Setup-Win11-x64.exe**，无需解压或另外下载 MSIX。
2. 运行安装包，允许安装器请求的管理员授权。使用兼容 ZIP 时，仍需完整解压后运行 **Install-Win11.exe**，不要只安装 MSIX。
3. 从开始菜单搜索 **FolderNote 设置**。首次安装默认开启双击空白处返回上一级；备注和中键快速定位默认关闭。需要备注菜单时，开启“文件夹备注”并保存。
4. 关闭并重新打开需要使用的文件夹窗口。安装器使用独立版本目录覆盖升级，不强制结束资源管理器，也不要求注销。

安装器将应用包安装与导航自动加载注册合并处理。首层菜单版要求当前账户自身获得管理员授权；使用另一管理员的凭据时会停止，避免安装到错误账户。组织策略可能禁止未签名包或资源管理器扩展，程序不会绕过这些策略。

## 功能和升级

- 设置窗口提供功能设置、置顶与历史、快捷搜索、盒子样式、右键菜单管理和文件夹入口管理，左下角显示当前运行版本。
- 桌面盒子保留原生桌面；桌面搜索可包含盒子各标签中的文件，操作及适用范围见[桌面盒子](../docs/USER_GUIDE.md#桌面盒子)和[快捷搜索](../docs/USER_GUIDE.md#中文首字母快速定位)。
- 备注、双击导航和中键快速定位可以独立启停。关闭备注功能只隐藏菜单，已有备注保留。
- 开启“中键快速定位”后，桌面和资源管理器均可使用菜单，并运行小型后台组件；从桌面选择文件夹会打开资源管理器窗口。勾选“同时支持文件与文件夹选择对话框”还可在标准打开 / 保存、选择文件夹及旧式“浏览文件夹”窗口使用。关闭中键快速定位后组件退出。
- 旧式窗口支持经典与可调整大小样式，菜单只提交目录定位，不点击“确定”；已有置顶和历史可用，但不推测树中当前目录，因此不显示“置顶当前文件夹”图标。管理员软件及自绘窗口不在支持范围；目标应用仍可按根目录或过滤规则拒绝某些路径。
- Windows 11 使用系统原生标签。FolderNote 的多标签栏、标签滚轮切换和悬停关闭按钮仅用于 Windows 10。
- 运行新版 **FolderNote-Setup-Win11-x64.exe** 即可覆盖升级，保留原有开关、主题、置顶、历史与盒子布局。非常早期版本的 MSIX 私有设置不会自动迁移，可重新打开设置并保存。
- 设置中的 **检查更新** 会选择本版本对应的安装包并验证 SHA-256。开启自动更新后会提示可用版本，需要管理员授权时仍由用户确认安装。
- 已运行的资源管理器可能缓存旧 DLL；关闭重开后仍未切换时，需要在结束文件复制 / 移动后重启资源管理器。

## 卸载和排查

在 Windows **设置 → 应用** 中卸载 **FolderNote 系统工具**，或运行安装目录内的 **Uninstall.exe**，完整移除当前用户的菜单包及导航组件，保留用户文件、备注、设置、访问记录和盒子布局。仅删除同名 MSIX 包不会清理独立导航注册；`Install.exe --uninstall` 也不会移除 MSIX 包。

设置已保存但功能无反应时，先重新打开文件夹窗口，再检查设置左下角版本；可点击“复制诊断信息”查看扩展加载和选项状态。提交问题时请说明 Windows 版本、程序版本以及“新窗口 / 新标签页 / 旧窗口”中的复现情况。

## 验证与发布范围

1.9.12 已完成 GitHub Actions 构建、自动测试和打包。公开发布的 Win11 独立安装包已通过版本、SHA-256、内置文件和软件图标校验。主要实机验证环境仍为 Windows 10 22H2；上述检查不能视作 Windows 11 各版本安装、菜单显示及全部交互的实机验收。

当前为未签名的个人测试包。安装使用 Windows 11 的未签名包安装能力，不导入证书、不启用开发者模式、不修改安全策略；正式分发前需要单独完成签名和目标系统验收。
